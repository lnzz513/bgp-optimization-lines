## 一、"大陆优化"到底优化了什么：先分清四种线路

香港服务器到大陆的访问体验，本质上由回程线路决定。恒创把香港二区的线路分成四档，命名很直白，但容易混：

- **BGP 精品线路**：电信走 CN2 GIA / CTGNet，移动走 CMI，联通走国内骨干直连，三网都是双向全程优化。官方给的数据是国内访问延迟低至 10ms，高峰期也不容易拥堵。这是恒创香港产品里大陆访问体验最好的一档，也是真正意义上"大陆优化"的核心。
- **BGP 优化线路**：官方原话是"中港互访速度普通，性价比高"。也就是说，它确实做了大陆方向优化，但优化程度不如精品线，价格更低。预算有限、对延迟不极致敏感的业务，选这档更划算。
- **BGP 国际线路**：标配国际大带宽，主打海外稳定访问，大陆方向不是重点。如果你的用户主要在海外，反而选这档更对路。
- **BGP 高防线路**：在优化线路基础上叠加 DDoS 防护，官方标称最高 300G 防护能力，攻击来了自动切高防线路清洗。适合经常挨打的业务。

一个常见的误区是把"优化线路"直接等同于"大陆优化最强"。其实按恒创的分层，**大陆访问体验最好的是精品线路（CN2 GIA），优化线路是性价比档，国际线路基本不为大陆访问做特别优化**。如果你冲着"大陆优化"四个字来，精品线路才是第一选择，优化线路是退而求其次的省钱方案。

## 七、几个常被问到的问题

**Q：香港服务器要备案吗？**
不需要。香港属于境外节点，免 ICP 备案，开通即用。但内容仍需遵守香港及大陆相关法律法规，恒创明确禁止放置违法违规信息。

**Q：CN2 GIA 和 CN2 GT 有什么区别？**
CN2 GIA 是 CN2 里的高端线路，全程双向优化，延迟低、高峰期稳定；CN2 GT 是 CN2 的普通档，部分路段会走普通 163 骨干，高峰期容易拥堵。恒创精品线路走的是 CN2 GIA，不是 GT——这点在同类产品里是核心差异，下单前可以要求客服确认。

**Q：大陆访问延迟大概多少？**
恒创官方给的数据是精品线路国内访问低至 10ms，实际体验因地区和运营商而异，电信、联通方向通常 10–40ms，移动方向也在优化范围内。优化线路会比精品线高一截，国际线路到大陆延迟会明显更高。

**Q：可以随时升级配置吗？**
可以在线升级 CPU、内存、带宽，无需迁移数据。但降级不一定支持，下单时别一开始就拉满配置，先小后大更稳。

**Q：恒创的香港机房什么级别？**
官方标称 TierⅢ+ 精品机房，2N 冗余，可用性 99.982%，SLA 承诺 99.9% 在线率，低于标准 100% 补偿。香港一区只提供 BGP 精品线路，香港二区提供精品 / 优化 / 国际 / 高防四种线路——选二区才能选到优化线路，一区只有精品。

**Q：云服务器和物理服务器怎么选？**
预算敏感、业务量小、需要弹性扩容——选云服务器。对 IO、CPU 稳定性有硬要求、不想被虚拟化邻居影响、业务量大——选物理服务器。中间档可以考虑计算型云服务器，CPU 独享但仍是虚拟化。
